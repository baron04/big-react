## Ref数据结构

`Ref`存在3种数据结构：

- `string`
- `(instance: T) => void`

```
<div ref={dom => console.log(dom)}></div>
```

- `{current: T}`

```
<div ref={domRef}></div>
```

## HostComponent Ref工作流程

### 1. 标记`Ref`

标记`Ref`需要满足：

- `mount`时：存在`ref`
- `update`时：`ref`引用变化

标记的时机包括：

- `beginWork`
- `completeWork`

### 2. 执行`Ref`操作

包括两类操作：

1. 对于正常的绑定操作：
   - 解绑之前的`ref`（`mutation`阶段）
   - 绑定新的`ref`（`layout`阶段）
2. 对于组件卸载：
   - 解绑之前的`ref`
